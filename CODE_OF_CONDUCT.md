# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text lives at the canonical source and is the authoritative version:

→ <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## TL;DR

- Be kind, assume good faith, criticize ideas rather than people.
- Harassment, discrimination, and personal attacks are not tolerated in any project space (issues, PRs, discussions, Discord, anywhere this project's name appears).
- Enforcement is up to the maintainer's discretion using the guidelines in the Covenant.

## Reporting

If something happens that you think violates this code:

- **Email:** 4knightsinteractivestudios@gmail.com
- **Subject:** `[sbox-ui-designer CoC]`

Reports are treated confidentially. You will get a response within 7 days.

## Scope

This code applies to all project spaces and to anyone representing the project in public — using the project name, an official email, posting via an official social media account, or acting as an appointed representative at an event.
